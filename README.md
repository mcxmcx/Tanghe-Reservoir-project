# Tanghe-Reservoir-project
Selective withdrawal and reservoir warming

This repository provides model inputs and post-processing code supporting the manuscript “Climate-resilient selective withdrawal scheduling to limit deep-water warming in stratified reservoirs.” The study evaluates the thermal performance of seasonal withdrawal schedules under future climate conditions.

The repository contains the CE-QUAL-W2 model configuration and input files for Tanghe Reservoir, China. Meteorological forcing data are provided for Tanghe and the six additional locations examined in the cross-climate experiments. These experiments retain the Tanghe Reservoir configuration while varying climatic forcing to assess the climatic sensitivity of withdrawal performance. The accompanying R scripts support post-processing and analysis of the simulation outputs.

These materials are publicly available to support reproducibility of the modelling workflow and facilitate further research on reservoir thermal management. When using the files, please cite the associated manuscript and acknowledge the original meteorological data sources.
